# PlanimetryAI

**PlanimetryAI** is an integrated suite of tools to process architectural and engineering planimetries using AI, automation, and standardization.

## Projects in this repository

### 🔍 PlanParser
Parses input planimetries in **PDF**, **DWG**, or **DXF** formats and transforms them into a structured format suitable for machine learning and algorithmic processing.

### 💬 PlanNL
Enables **natural language querying** over architectural plans, allowing users to ask questions and extract insights without technical commands.

### 🧠 Plan2HVAC
Given a parsed planimetry, this tool automatically generates a **precise HVAC layout** (heating/cooling systems), drawing it with accurate scaling directly on the plan.

### 📐 PlanimetryDigitalConventions
A **manifesto and specification** to define a **national digital standard** for planimetries: unified structure, embedded metadata, and interoperability across platforms.

## Vision

Our goal is to revolutionize how floorplans and engineering drawings are created, interpreted, and processed—by making them machine-readable, AI-friendly, and universally standardized.
